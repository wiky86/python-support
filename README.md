# py-data-lab (콘텐츠 & 스펙 패키지)

"파이썬을 활용한 데이터 분석" 학습 공간의 **개발 착수 패키지**입니다. 아직 앱 코드는 없고, 개발 에이전트(Antigravity)가 구현하는 데 필요한 명세와 콘텐츠 데이터가 들어 있습니다.

## 폴더 구조

```
py-data-lab/
├── README.md                     # 이 파일
├── docs/
│   ├── SPEC.md                   # 전체 개발 스펙 (최우선 기준 문서)
│   └── ANTIGRAVITY_PROMPT.md     # Antigravity에 붙여넣을 지시 프롬프트
└── content/
    ├── config/
    │   ├── xp-rules.json         # XP 적립·레벨 공식
    │   └── badges.json           # 배지 목록·획득 조건
    └── tracks/
        ├── track1/               # 트랙1: 파이썬 기초 다지기 (완성)
        │   ├── track.json
        │   ├── topics/ (t1~t7)   # 변수, 리스트, 딕셔너리, 조건문, 반복문, 함수, 컴프리헨션
        │   └── project.json      # 미니 프로젝트: 학생 점수 분석기
        └── track2/               # 트랙2: NumPy로 수치 다루기 (완성)
            ├── track.json
            ├── topics/ (t1~t6)   # 배열, 인덱싱, 벡터연산, 브로드캐스팅, 통계함수, 조건필터링
            └── project.json      # 미니 프로젝트: 기온 데이터 통계 요약
```

> 트랙2부터는 빈칸 채우기(fillBlanks)와 프로젝트 미션(missions)에 `explain`(상세 해설) 필드가 추가되었습니다. 트랙1은 추후 같은 형식으로 소급 예정입니다.

## 사용 방법

1. 이 폴더 전체를 Antigravity 워크스페이스에 넣습니다.
2. `docs/ANTIGRAVITY_PROMPT.md`의 초기 지시 프롬프트를 에이전트에 전달합니다.
3. 에이전트가 `docs/SPEC.md`와 `content/`를 근거로 앱을 구현합니다.

## 현재 상태

- 콘텐츠: 트랙1(토픽 7개), 트랙2(토픽 6개) + 각 미니 프로젝트 완성. 트랙3~7은 동일 형식으로 추후 추가 예정.
- 게임화 규칙(XP/레벨/배지): 확정.
- 앱 코드: 미구현(에이전트가 생성).

## 핵심 원칙 (자세한 내용은 SPEC.md)

- 콘텐츠는 DB가 아니라 `content/` 정적 파일이 원본.
- Supabase는 인증 + 진도/통계/배지 저장 전용, RLS 필수.
- 코드 실행 엔진 없음. 빈칸 채우기는 문자열 비교 + 저장된 예상 출력.
- 퀴즈는 파일 순서대로(랜덤 아님), 통과해야 다음 토픽 잠금 해제.
- 레벨은 저장하지 않고 누적 XP에서 계산.

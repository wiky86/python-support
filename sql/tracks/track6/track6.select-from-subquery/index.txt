3:T7c9,## SELECT 절 서브쿼리 — 결과에 값 더하기

서브쿼리를 SELECT 절에 넣으면, 조회 결과에 **계산된 값 하나를 열로 추가**할 수 있습니다.

```sql
SELECT emp_name, salary,
       (SELECT ROUND(AVG(salary)) FROM employees) AS 전체평균
FROM employees;
```

각 직원 행 옆에 '전체 평균 급여'(약 4163)를 함께 표시합니다. 이러면 '이 직원이 평균과 얼마나 차이 나는지'를 눈으로 비교하기 좋습니다. SELECT 절 서브쿼리는 보통 값 하나(스칼라)를 반환해야 합니다.

## FROM 절 서브쿼리 — 임시 테이블처럼

서브쿼리를 FROM 절에 넣으면, 그 **결과를 하나의 임시 테이블처럼** 사용할 수 있습니다. '집계한 결과를 다시 조회'할 때 유용합니다.

```sql
SELECT *
FROM (SELECT dept_id, ROUND(AVG(salary)) AS avg_sal
      FROM employees
      GROUP BY dept_id) AS dept_avg
WHERE dept_avg.avg_sal >= 4000;
```

- 안쪽 서브쿼리가 '부서별 평균 급여' 표를 만듭니다.
- 바깥 쿼리는 그 표를 `dept_avg`라는 임시 테이블로 보고, 평균이 4000 이상인 부서만 조회합니다.

결과: 영업부(4600), 개발부(4100), 마케팅부(4800).

## FROM 서브쿼리에는 별칭 필수

FROM 절 서브쿼리는 **반드시 별칭**을 붙여야 합니다(위의 `AS dept_avg`). 임시 테이블에 이름을 줘야 바깥에서 참조할 수 있기 때문입니다.

## HAVING 대신 FROM 서브쿼리?

'부서별 평균이 4000 이상'은 HAVING으로도 됩니다(`GROUP BY dept_id HAVING AVG(salary) >= 4000`). FROM 서브쿼리는 집계 결과를 한 번 더 가공하거나, 여러 단계로 나눠 생각할 때 유용합니다. 상황에 맞게 고르면 됩니다.

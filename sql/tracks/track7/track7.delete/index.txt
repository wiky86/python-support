3:T7cb,## 행 삭제하기

**DELETE**는 테이블에서 행을 삭제합니다. '퇴사한 직원을 지운다' 같은 경우에 씁니다.

## 기본 문법

```sql
DELETE FROM employees
WHERE emp_id = 9;
```

- **DELETE FROM 테이블**: 삭제할 테이블.
- **WHERE 조건**: 어떤 행을 삭제할지.

이 쿼리는 emp_id가 9인 직원을 삭제합니다.

## ⚠️ WHERE를 빠뜨리면 전멸

UPDATE와 마찬가지로, **DELETE에서 WHERE를 빠뜨리면 모든 행이 삭제**됩니다.

```sql
DELETE FROM employees;   -- 위험! 전 직원 데이터가 사라짐
```

테이블 구조는 남지만 안의 데이터가 전부 사라집니다. DELETE는 UPDATE보다 더 위험할 수 있으니, **반드시 WHERE를 확인**하고 실행 전 같은 조건으로 SELECT해 대상을 확인하세요.

## 조건에 맞는 여러 행 삭제

```sql
DELETE FROM employees
WHERE dept_id = 4;
```

마케팅부(4) 소속 직원을 모두 삭제합니다. WHERE 조건에 맞는 여러 행이 한꺼번에 삭제됩니다.

## DELETE vs TRUNCATE

테이블의 **모든 행**을 빠르게 비우려면 TRUNCATE라는 명령도 있습니다.

```sql
TRUNCATE TABLE 테이블;
```

- **DELETE**: 행을 하나씩 삭제(WHERE로 일부만 가능, 되돌리기 가능한 경우 있음).
- **TRUNCATE**: 전체를 한 번에 비움(빠르지만 WHERE 불가, 되돌리기 어려움).

일부만 지울 때는 DELETE, 전체를 초기화할 때는 TRUNCATE를 쓰지만, TRUNCATE는 신중해야 합니다.

## DELETE vs DROP

헷갈리기 쉬운데 다릅니다.

- **DELETE**: 테이블 안의 **행(데이터)** 을 삭제. 테이블 자체는 남음.
- **DROP TABLE**: **테이블 자체**를 삭제. 구조까지 사라짐(다음 토픽).

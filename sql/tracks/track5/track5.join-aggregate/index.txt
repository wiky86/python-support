3:T6d9,## 조인한 결과를 그룹 집계

트랙4의 집계(GROUP BY)와 이번 조인을 결합하면 강력해집니다. 예를 들어 '부서 **이름**별 평균 급여'는 조인 없이는 부서 번호(dept_id)로만 볼 수 있었지만, 조인하면 부서 이름으로 볼 수 있습니다.

```sql
SELECT d.dept_name, ROUND(AVG(e.salary)) AS avg_sal
FROM employees e
JOIN departments d ON e.dept_id = d.dept_id
GROUP BY d.dept_name;
```

두 테이블을 조인한 뒤, 부서 이름으로 그룹을 나눠 평균 급여를 구합니다. 결과: 개발부 4100, 마케팅부 4800, 영업부 4600, 인사부 3500.

## 부서별 인원 (이름으로)

```sql
SELECT d.dept_name, COUNT(*) AS cnt
FROM employees e
JOIN departments d ON e.dept_id = d.dept_id
GROUP BY d.dept_name
ORDER BY cnt DESC;
```

부서 이름별 인원을 많은 순으로 봅니다. 개발부(3), 영업부(2), 인사부(2), 마케팅부(1).

## 근무지별 집계

departments의 `location`(근무지)으로도 그룹화할 수 있습니다.

```sql
SELECT d.location, COUNT(*) AS cnt
FROM employees e
JOIN departments d ON e.dept_id = d.dept_id
GROUP BY d.location;
```

근무지별 직원 수: 서울 6명, 부산 2명. 조인 덕분에 employees에 없는 location 정보로도 집계할 수 있습니다.

## 절의 순서

조인이 들어가도 순서는 그대로입니다: FROM(+JOIN) → WHERE → GROUP BY → HAVING → ORDER BY. 조인은 FROM 부분에서 테이블을 합치는 단계라고 보면 됩니다.

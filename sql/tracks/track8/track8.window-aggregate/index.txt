3:T7f6,## 집계를 각 행 옆에

앞에서 잠깐 본 것처럼, SUM·AVG·COUNT 같은 집계 함수도 OVER와 함께 쓰면 윈도우 함수가 됩니다. 각 행을 유지하면서 집계 값을 붙이므로, **개별 값과 집계를 비교**하기 좋습니다.

## 전체 대비 비교

```sql
SELECT emp_name, salary,
       ROUND(AVG(salary) OVER ()) AS 전체평균,
       salary - ROUND(AVG(salary) OVER ()) AS 평균과의차이
FROM employees;
```

각 직원의 급여가 전체 평균과 얼마나 차이 나는지 한눈에 봅니다. 김철수는 평균(4163)보다 +1837, 윤서연은 -1163 처럼요. 개별 값과 집계를 나란히 두고 뺄셈까지 하는 것이 윈도우 함수의 강점입니다.

## 부서 내 비율

```sql
SELECT emp_name, dept_id, salary,
       ROUND(salary * 100.0 / SUM(salary) OVER (PARTITION BY dept_id), 1) AS 부서내비중
FROM employees;
```

각 직원의 급여가 자기 부서 총급여에서 차지하는 비율(%)을 구합니다. 부서별 총합(윈도우)으로 나눠 개인 비중을 계산합니다.

## 누적 합계 — ORDER BY와 함께

OVER 안에 ORDER BY를 넣으면 **누적** 계산이 됩니다.

```sql
SELECT emp_name, salary,
       SUM(salary) OVER (ORDER BY salary) AS 누적합
FROM employees;
```

급여를 낮은 순으로 정렬하면서, 그 행까지의 급여 누적 합계를 구합니다. 낮은 급여부터 차곡차곡 더해집니다. 매출 누적, 랭킹 누적 인원 등에 활용됩니다.

## COUNT 윈도우

```sql
SELECT emp_name, dept_id,
       COUNT(*) OVER (PARTITION BY dept_id) AS 부서인원
FROM employees;
```

각 직원 옆에 그 부서의 총 인원을 표시합니다. '나는 3명짜리 부서 소속'임을 각 행에서 알 수 있습니다.

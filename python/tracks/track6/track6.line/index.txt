3:T719,## 선 그래프는 언제?

선 그래프는 시간이나 순서에 따라 값이 어떻게 변하는지(추세)를 볼 때 씁니다. 월별 매출, 일별 방문자, 연도별 인구처럼 "흐름"이 있는 데이터에 적합합니다.

## 기본 선 그래프

```python
import matplotlib.pyplot as plt

매출 = [100, 105, 98, 130, 145]
plt.plot(매출)
plt.show()
```

값들이 순서대로 선으로 이어집니다. x축은 자동으로 0, 1, 2, 3, 4(순서)가 됩니다.

## x축 값 지정하기

x축에 의미 있는 값(예: 월)을 넣으려면 `plot(x, y)` 형태로 두 개를 줍니다.

```python
월 = ["1월", "2월", "3월", "4월", "5월"]
매출 = [100, 105, 98, 130, 145]
plt.plot(월, 매출)
plt.show()
```

이제 x축에 월 이름이, y축에 매출이 표시됩니다. 첫 번째가 x축, 두 번째가 y축입니다.

## 여러 선 한 그래프에 그리기

`plot`을 여러 번 호출하면 한 그래프에 여러 선이 겹쳐 그려집니다. 두 지점의 매출을 비교할 때 유용합니다.

```python
plt.plot(월, 서울매출)
plt.plot(월, 부산매출)
plt.show()
```

두 선이 함께 나타나, 어느 쪽이 더 높은지 흐름을 비교할 수 있습니다.

## 선 모양·색 바꾸기

`plot`에 옵션을 주어 선의 색이나 모양을 바꿀 수 있습니다.

```python
plt.plot(매출, color="red")            # 빨간 선
plt.plot(매출, marker="o")             # 각 점에 동그라미 표시
```

`marker="o"`를 주면 각 데이터 지점에 점이 찍혀, 값의 위치를 명확히 볼 수 있습니다.

## pandas와 함께 쓰기

DataFrame의 열을 바로 그릴 수도 있습니다.

```python
plt.plot(df["월"], df["매출"])
plt.show()
```

3:T981,## 탐색에서 발견한 문제를 고친다

탐색 단계에서 결측치, 잘못된 타입, 중복 같은 문제를 발견했다면, 이제 정제 단계에서 실제로 고칩니다. 트랙4에서 배운 기술들을 실전 데이터에 적용하는 단계입니다.

이 트랙의 카페 데이터인데, 이번엔 일부러 문제를 심어둔 버전입니다.

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "요일": ["월", "화", "수", "목", "금"],
    "메뉴": ["아메리카노", "라떼", "아메리카노", "라떼", "아메리카노"],
    "판매량": ["50", "45", "55", "48", "60"],   # 문자열로 들어옴!
    "매출": [150000, 180000, np.nan, 192000, 180000]   # 결측치 있음!
})
```

탐색해 보면 두 가지 문제가 보입니다: 판매량이 문자열이고, 매출에 결측치가 있습니다.

## 문제 1 해결: 판매량 타입 변환

판매량이 문자열("50")이라 계산이 안 됩니다. 정수로 바꿉니다.

```python
df["판매량"] = df["판매량"].astype(int)
```

이제 판매량으로 합계·평균을 낼 수 있습니다.

## 문제 2 해결: 매출 결측치 처리

매출에 빈 값(NaN)이 있습니다. 여기서는 평균으로 채워 보겠습니다.

```python
매출평균 = df["매출"].mean()
df["매출"] = df["매출"].fillna(매출평균)
```

결측치를 그 열의 평균으로 채우면, 전체 경향을 크게 왜곡하지 않으면서 빈 값을 메울 수 있습니다. (0으로 채우거나 행을 삭제할 수도 있으며, 상황에 따라 선택합니다.)

## 정제 후 확인

정제가 잘 됐는지 다시 확인합니다.

```python
df.info()          # 타입과 결측치 재확인
df.isna().sum()    # 결측치가 0이 됐는지
```

정제 후에는 항상 결과를 다시 점검하는 것이 좋습니다.

## 새 열 만들기 — 파생 변수

정제된 데이터로 분석에 도움이 될 새 열을 만들 수 있습니다. 예를 들어 잔당 평균 매출(매출/판매량)을 계산합니다.

```python
df["잔당매출"] = df["매출"] / df["판매량"]
```

3:T9b1,## 데이터 분석은 순서가 있다

지금까지 파이썬 기초, NumPy, pandas, 그룹화, 시각화를 하나씩 배웠습니다. 실제 분석에서는 이것들을 정해진 흐름으로 엮어 씁니다. 이 트랙에서는 그 전체 흐름을 하나의 데이터로 처음부터 끝까지 경험합니다.

## 데이터 분석의 6단계

| 단계 | 하는 일 | 사용 기술 |
|---|---|---|
| 1. 문제 정의 | 무엇을 알고 싶은지 정하기 | (생각) |
| 2. 탐색 | 데이터가 어떻게 생겼는지 살피기 | shape, head, info |
| 3. 정제 | 결측치·중복·타입 정리 | fillna, drop_duplicates, astype |
| 4. 집계 | 그룹별로 요약해 패턴 찾기 | groupby, agg, pivot_table |
| 5. 시각화 | 그래프로 표현 | plot, bar, hist |
| 6. 해석 | 결과에서 의미 끌어내기 | (생각) |

이 순서가 데이터 분석의 기본 뼈대입니다.

## 1단계: 문제 정의가 가장 중요하다

분석을 시작하기 전에 "무엇을 알고 싶은가?"를 먼저 정해야 합니다. 목표가 없으면 데이터를 봐도 무엇을 찾아야 할지 막막합니다. 좋은 분석은 좋은 질문에서 시작합니다.

## 이 트랙의 데이터: 가상 카페 판매 기록

```python
import pandas as pd
df = pd.DataFrame({
    "날짜": ["1일", "2일", "3일", "4일", "5일", "6일", "7일"],
    "요일": ["월", "화", "수", "목", "금", "토", "일"],
    "메뉴": ["아메리카노", "라떼", "아메리카노", "라떼", "아메리카노", "라떼", "아메리카노"],
    "판매량": [50, 45, 55, 48, 60, 90, 85],
    "매출": [150000, 180000, 165000, 192000, 180000, 360000, 255000]
})
```

이 카페 사장님이 알고 싶은 것은 이런 질문들일 수 있습니다.
- "어느 요일에 가장 많이 팔릴까?" (요일별 패턴)
- "주말이 평일보다 매출이 높을까?"
- "판매량이 많은 날은 매출도 높을까?"

## 질문에 따라 쓰는 기술이 달라진다

- "요일별 매출" -> groupby (집계)
- "매출 추세" -> 선 그래프 (시각화)
- "판매량과 매출의 관계" -> 산점도 (시각화)

문제를 정의하면, 어떤 기술을 써야 할지 자연스럽게 정해집니다. 그래서 문제 정의가 먼저입니다.

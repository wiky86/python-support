3:T920,## 정제된 데이터에서 패턴 찾기

데이터가 깨끗해졌으니, 이제 그룹별로 묶어 요약하며 의미 있는 패턴(인사이트)을 찾습니다. 트랙5에서 배운 groupby, agg, pivot_table을 실전 질문에 적용하는 단계입니다.

깨끗하게 정제된 카페 데이터를 사용합니다.

```python
import pandas as pd
df = pd.DataFrame({
    "요일": ["월", "화", "수", "목", "금", "토", "일"],
    "구분": ["평일", "평일", "평일", "평일", "평일", "주말", "주말"],
    "메뉴": ["아메리카노", "라떼", "아메리카노", "라떼", "아메리카노", "라떼", "아메리카노"],
    "판매량": [50, 45, 55, 48, 60, 90, 85],
    "매출": [150000, 180000, 165000, 192000, 180000, 360000, 255000]
})
```

## 질문 1: 평일 vs 주말, 매출 차이는?

```python
df.groupby("구분")["매출"].mean()
```

출력:
```
구분
주말    307500.0
평일    173400.0
Name: 매출, dtype: float64
```

주말 평균 매출(307,500)이 평일(173,400)보다 훨씬 높습니다. "주말에 장사가 잘 된다"는 인사이트를 얻었습니다.

## 질문 2: 메뉴별 총 판매량은?

```python
df.groupby("메뉴")["판매량"].sum()
```

어느 메뉴가 더 많이 팔리는지 알 수 있습니다.

## 질문 3: 여러 지표를 한 번에 — agg

```python
df.groupby("구분")["매출"].agg(["sum", "mean", "count"])
```

평일/주말 각각의 총매출, 평균매출, 일수를 한 표로 봅니다.

## 질문 4: 구분 x 메뉴 교차 분석 — pivot_table

```python
df.pivot_table(index="구분", columns="메뉴", values="매출", aggfunc="sum")
```

평일/주말과 메뉴를 교차해, 어느 조합의 매출이 큰지 2차원으로 봅니다.

## 인사이트를 정리하기

집계 결과에서 얻은 발견을 정리하면 이렇습니다.
- 주말 매출이 평일의 약 1.8배
- 특정 메뉴가 더 잘 팔림
- 주말+특정 메뉴 조합이 매출 기여가 큼

이런 발견이 "분석의 결과물"입니다. 다음 단계에서 이를 그래프로 표현하고 해석합니다.

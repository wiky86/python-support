3:T97f,## 인사이트를 그래프로 보여주기

집계로 찾은 인사이트를 그래프로 표현하면, 발견한 패턴이 훨씬 설득력 있게 전달됩니다. 트랙6에서 배운 시각화를, 앞서 집계한 카페 데이터 결과에 적용하는 단계입니다. "무엇을 보여줄지"에 따라 그래프 종류를 고르는 것이 핵심입니다.

카페 데이터입니다.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "요일": ["월", "화", "수", "목", "금", "토", "일"],
    "판매량": [50, 45, 55, 48, 60, 90, 85],
    "매출": [150000, 180000, 165000, 192000, 180000, 360000, 255000]
})
```

## 요일별 매출 추세 -> 선 그래프

요일 순서에 따른 매출 변화를 봅니다.

```python
plt.plot(df["요일"], df["매출"], marker="o")
plt.title("요일별 매출 추이")
plt.xlabel("요일")
plt.ylabel("매출")
plt.show()
```

월요일부터 금요일까지 완만하다가 토·일에 크게 오르는 흐름이 나타나, "주말에 매출이 급증"하는 패턴이 한눈에 보입니다.

## 요일별 판매량 비교 -> 막대 그래프

각 요일의 판매량 크기를 비교합니다.

```python
plt.bar(df["요일"], df["판매량"])
plt.title("요일별 판매량")
plt.xlabel("요일")
plt.ylabel("판매량")
plt.show()
```

토요일 막대가 가장 높아 판매량이 주말에 몰린다는 걸 보여줍니다.

## 집계 결과를 바로 그리기

groupby 결과도 바로 그래프로 그릴 수 있습니다.

```python
구분별매출 = df.groupby("구분")["매출"].mean()
plt.bar(구분별매출.index, 구분별매출.values)
plt.show()
```

집계(평일/주말 평균)를 막대로 그려 그룹 간 차이를 시각적으로 대비합니다.

## 판매량과 매출의 관계 -> 산점도

두 값의 관계를 봅니다.

```python
plt.scatter(df["판매량"], df["매출"])
plt.xlabel("판매량")
plt.ylabel("매출")
plt.show()
```

판매량이 많은 날은 매출도 높은, 오른쪽 위로 향하는 점 배치가 나타나 양의 관계를 확인할 수 있습니다.

| 값의 분포 | 히스토그램 |

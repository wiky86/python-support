3:T724,## agg란?

`agg`(aggregate의 약자)는 여러 집계를 한 번에 구하는 도구입니다. 앞에서는 합계 따로, 평균 따로 구했지만, agg를 쓰면 "합계와 평균과 개수"를 한 번에 표로 만들 수 있습니다. 열마다 다른 집계를 적용할 수도 있습니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "지점": ["서울", "부산", "서울", "부산"],
    "매출": [100, 80, 120, 90]
})
```

## 한 열에 여러 집계 — 리스트로

집계 함수 이름을 문자열 리스트로 넣습니다.

```python
df.groupby("지점")["매출"].agg(["sum", "mean", "count"])
```

출력:
```
      sum   mean  count
지점
부산   170   85.0      2
서울   220  110.0      2
```

한 번에 합계·평균·개수가 표로 나옵니다. 함수 이름은 `"sum"`처럼 따옴표로 감싼 문자열입니다.

## 결과는 DataFrame

집계 하나만 하면 Series(세로 나열)였지만, agg로 여러 개를 하면 각 집계가 열이 되는 DataFrame(표)이 됩니다.

## 열마다 다른 집계 — 딕셔너리로

여러 열에 서로 다른 집계를 적용할 수도 있습니다.

```python
df2 = pd.DataFrame({
    "지점": ["서울", "부산", "서울"],
    "매출": [100, 80, 120],
    "방문객": [50, 30, 60]
})
df2.groupby("지점").agg({"매출": "sum", "방문객": "mean"})
```

"매출은 합계, 방문객은 평균"처럼 열별로 다른 집계를 지정합니다. 딕셔너리의 키가 열, 값이 집계 함수입니다.

## 자주 쓰는 조합

매출 데이터라면 "합계(총매출), 평균(건당 매출), 개수(거래 건수)"를 한 번에 보는 경우가 많습니다. agg는 이런 요약 표를 한 줄로 만들어줍니다.

3:T747,## 피벗 테이블이란?

피벗 테이블은 데이터를 "행 기준 x 열 기준"의 2차원 표로 요약하는 도구입니다. 엑셀의 피벗 테이블과 같은 개념입니다. 예를 들어 "지점(행) x 월(열)별 매출 합계"처럼 두 기준으로 교차 집계할 때 강력합니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "지점": ["서울", "서울", "부산", "부산"],
    "월": ["1월", "2월", "1월", "2월"],
    "매출": [100, 120, 80, 90]
})
```

## pivot_table의 기본 구조

```python
df.pivot_table(index="지점", columns="월", values="매출", aggfunc="sum")
```

출력:
```
월      1월   2월
지점
부산     80   90
서울    100  120
```

네 가지를 지정합니다:
- `index="지점"` -> 행 기준
- `columns="월"` -> 열 기준
- `values="매출"` -> 집계할 값
- `aggfunc="sum"` -> 집계 방법

지점이 세로, 월이 가로로 배치되어 교차 지점에 매출 합계가 들어갑니다.

## groupby와 뭐가 다른가?

groupby는 보통 결과가 세로로 길게 나오지만, 피벗 테이블은 두 기준을 행과 열로 나눠 2차원 표로 보여줍니다. "지점별 월별"처럼 두 축으로 비교할 때 피벗 테이블이 훨씬 읽기 좋습니다.

## 집계 방법 바꾸기 — aggfunc

`aggfunc`로 합계 대신 평균, 개수 등을 지정할 수 있습니다.

```python
df.pivot_table(index="지점", columns="월", values="매출", aggfunc="mean")
```

## 빈 칸은 NaN

특정 조합에 데이터가 없으면 그 칸은 NaN(결측치)이 됩니다. 예를 들어 부산의 3월 데이터가 없으면 부산-3월 칸이 비게 됩니다. 이럴 때 `fill_value=0`을 주면 빈 칸을 0으로 채울 수 있습니다.

df.pivot_table(index="지점", columns="월", values="매출", aggfunc="sum", fill_value=0)

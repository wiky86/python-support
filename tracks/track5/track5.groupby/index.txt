3:T7c0,## 그룹화란?

그룹화(groupby)는 같은 값을 가진 행끼리 묶어서 그룹별로 계산하는 것입니다. "지점별 매출 합계", "부서별 평균 연봉", "요일별 방문자 수"처럼 "~별"로 요약하는 모든 분석의 핵심입니다. 엑셀의 피벗 테이블과 비슷한 역할을 합니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "지점": ["서울", "부산", "서울", "부산", "서울"],
    "매출": [100, 80, 120, 90, 110]
})
```

서울과 부산 데이터가 섞여 있습니다. 이걸 지점별로 묶어 계산하려는 것입니다.

## groupby의 기본 구조

`groupby("기준열")`로 묶고, 그 뒤에 어떤 계산을 할지 정합니다.

```python
df.groupby("지점")["매출"].sum()
```

출력:
```
지점
부산    170
서울    330
Name: 매출, dtype: int64
```

읽는 방법: "지점으로 묶어서(groupby), 매출 열을([\"매출\"]), 합계 내라(sum())". 서울(100+120+110=330)과 부산(80+90=170)이 각각 계산됐습니다.

## 세 부분으로 나눠 이해하기

```
df.groupby("지점")   ["매출"]   .sum()
   무엇으로 묶나     어느 열을   어떤 계산
```

이 세 부분(묶을 기준 -> 계산할 열 -> 집계 함수)이 groupby의 기본 골격입니다.

## 결과의 인덱스는 그룹 이름

groupby 결과는 그룹 기준 값(부산, 서울)이 인덱스가 됩니다. 그래서 왼쪽에 지점 이름이 오고, 가나다순으로 정렬되어 나옵니다.

## 그룹 크기 세기 — size()

각 그룹에 행이 몇 개인지 셀 때는 `size()`를 씁니다.

```python
df.groupby("지점").size()
```

출력:
```
지점
부산    2
서울    3
dtype: int64
```

서울 3건, 부산 2건입니다.

3:T845,## 두 개 이상의 기준으로 묶기

지금까지는 한 열("지점")로만 묶었지만, 여러 열을 동시에 기준으로 삼을 수 있습니다. "지점별, 그리고 그 안에서 다시 상품별"처럼 계층적으로 묶는 것입니다. 더 세밀한 요약이 가능해집니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "지점": ["서울", "서울", "부산", "부산"],
    "상품": ["A", "B", "A", "B"],
    "매출": [100, 150, 80, 90]
})
```

## 여러 열로 묶기 — 리스트로 전달

groupby에 열 이름 리스트를 넣습니다.

```python
df.groupby(["지점", "상품"])["매출"].sum()
```

출력:
```
지점  상품
부산  A      80
     B      90
서울  A     100
     B     150
Name: 매출, dtype: int64
```

지점으로 먼저 묶고, 그 안에서 상품으로 다시 묶어 각 조합의 매출 합계가 나옵니다. 왼쪽 인덱스가 지점·상품 두 단계로 표시됩니다.

## 결과 읽는 법

`부산-A`는 80, `서울-B`는 150처럼 두 기준의 조합마다 값이 하나씩 나옵니다. 4개 조합(부산A, 부산B, 서울A, 서울B)이 각각 계산된 것입니다.

## 순서가 중요하다

`["지점", "상품"]`과 `["상품", "지점"]`은 묶는 순서가 달라 결과 표의 구조가 달라집니다. 앞에 온 기준이 바깥쪽(큰 묶음), 뒤가 안쪽(작은 묶음)이 됩니다.

## 표 형태로 바꾸기 — unstack()

여러 열로 묶은 세로로 긴 결과를, `unstack()`으로 2차원 표로 펼칠 수 있습니다.

```python
df.groupby(["지점", "상품"])["매출"].sum().unstack()
```

출력:
```
상품     A    B
지점
부산    80   90
서울   100  150
```

안쪽 기준(상품)이 열로 올라가 피벗 테이블과 비슷한 형태가 됩니다. 사실 이것은 앞 토픽의 pivot_table과 같은 결과입니다. 두 방법 모두 두 기준 교차 집계를 만들 수 있습니다.

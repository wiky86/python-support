3:T69e,## 다양한 집계 함수

groupby로 묶은 뒤에는 합계뿐 아니라 평균, 개수, 최댓값 등 여러 집계를 낼 수 있습니다. 이번엔 자주 쓰는 집계 함수들을 살펴봅니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "부서": ["영업", "개발", "영업", "개발", "영업"],
    "연봉": [4000, 5000, 4500, 6000, 3500]
})
```

## 합계 — sum()

```python
df.groupby("부서")["연봉"].sum()
```

부서별 연봉 총합입니다.

## 평균 — mean()

```python
df.groupby("부서")["연봉"].mean()
```

출력:
```
부서
개발    5500.0
영업    4000.0
Name: 연봉, dtype: float64
```

영업 평균 (4000+4500+3500)/3=4000, 개발 (5000+6000)/2=5500입니다.

## 개수 — count()

```python
df.groupby("부서")["연봉"].count()
```

각 그룹에서 연봉 값이 몇 개인지(결측치 제외) 셉니다.

## 최댓값·최솟값 — max(), min()

```python
df.groupby("부서")["연봉"].max()      # 부서별 최고 연봉
df.groupby("부서")["연봉"].min()      # 부서별 최저 연봉
```

## 주요 집계 함수 정리

| 함수 | 의미 |
|---|---|
| `sum()` | 그룹별 합계 |
| `mean()` | 그룹별 평균 |
| `count()` | 그룹별 개수(결측치 제외) |
| `max()` / `min()` | 그룹별 최대 / 최소 |
| `size()` | 그룹별 행 수(결측치 포함) |

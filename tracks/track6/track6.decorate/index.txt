3:T6f0,## 왜 꾸미나?

그래프만 덩그러니 있으면 보는 사람이 "이게 무슨 데이터지?"라고 헷갈립니다. 제목, 축 이름, 범례를 붙이면 그래프가 스스로 무엇을 말하는지 설명해줍니다. 남에게 전달하는 그래프라면 꾸미기는 필수입니다.

예제 데이터:

```python
import matplotlib.pyplot as plt
월 = ["1월", "2월", "3월"]
매출 = [100, 120, 90]
```

## 제목 붙이기 — plt.title()

```python
plt.plot(월, 매출)
plt.title("월별 매출")
plt.show()
```

그래프 위에 "월별 매출"이라는 제목이 표시됩니다.

## 축 이름 붙이기 — plt.xlabel(), plt.ylabel()

```python
plt.plot(월, 매출)
plt.xlabel("월")
plt.ylabel("매출(만원)")
plt.show()
```

x축 아래에 "월", y축 옆에 "매출(만원)"이 표시되어, 각 축이 무엇을 나타내는지 알려줍니다.

## 범례 붙이기 — label + plt.legend()

여러 선을 그릴 때 어느 선이 무엇인지 표시하려면, 각 선에 `label`을 주고 `plt.legend()`를 호출합니다.

```python
plt.plot(월, 서울매출, label="서울")
plt.plot(월, 부산매출, label="부산")
plt.legend()
plt.show()
```

그래프 한쪽에 "서울", "부산"이 색과 함께 표시되어 어느 선이 어느 지점인지 구분됩니다.

## 전체를 갖춘 그래프

```python
plt.plot(월, 매출)
plt.title("월별 매출 추이")
plt.xlabel("월")
plt.ylabel("매출(만원)")
plt.show()
```

제목·축 이름까지 갖추면 그래프만 봐도 내용을 이해할 수 있습니다.

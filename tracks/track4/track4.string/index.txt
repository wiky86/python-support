3:T81d,## 문자열 열 다루기

이름, 주소, 이메일처럼 글자로 된 데이터는 정리가 필요할 때가 많습니다. 앞뒤 공백 제거, 대소문자 통일, 특정 글자 포함 여부 확인 등이죠. pandas는 `.str` 접근자로 문자열 열 전체에 이런 작업을 한 번에 적용합니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "이름": [" 김철수", "이영희 ", "박민수"],
    "이메일": ["kim@A.com", "lee@b.COM", "park@c.com"]
})
```

## .str 접근자란?

문자열 열에 `.str`을 붙이면, 파이썬의 문자열 메서드를 열 전체에 적용할 수 있습니다. 각 칸의 문자열에 같은 처리가 한 번에 이루어집니다.

## 공백 제거 — str.strip()

앞뒤 공백을 제거합니다. 데이터 입력 시 실수로 들어간 공백을 정리할 때 필수입니다.

```python
df["이름"].str.strip()
```

`" 김철수"`, `"이영희 "`의 앞뒤 공백이 사라집니다.

## 대소문자 변환 — str.lower(), str.upper()

```python
df["이메일"].str.lower()      # 모두 소문자로
```

`"lee@b.COM"`이 `"lee@b.com"`이 됩니다. 이메일처럼 대소문자를 통일해야 하는 데이터에 유용합니다.

## 특정 글자 포함 여부 — str.contains()

특정 문자열이 포함됐는지 True/False로 확인합니다. 필터링과 함께 자주 씁니다.

```python
df["이메일"].str.contains("@")     # 모두 True
```

```python
# gmail 주소만 필터링하는 식으로 활용
df[df["이메일"].str.contains("gmail")]
```

## 바꾸기 — str.replace()

특정 문자열을 다른 것으로 바꿉니다.

```python
df["이메일"].str.replace(".com", ".net")
```

## 길이 재기 — str.len()

각 문자열의 글자 수를 셉니다.

```python
df["이름"].str.len()
```

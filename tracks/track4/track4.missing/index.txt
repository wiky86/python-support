3:T78f,## 결측치란?

결측치(missing value)는 값이 비어 있는 칸입니다. 실제 데이터에는 설문 미응답, 기록 누락 등으로 빈 칸이 흔하게 생깁니다. pandas는 이런 빈 값을 `NaN`(Not a Number)으로 표시하며, 분석 전에 이를 확인하고 처리하는 것이 데이터 정제의 첫걸음입니다.

예제 데이터 (일부 값이 비어 있음):

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, np.nan, 70]
})
print(df)
```

출력:
```
    이름    점수
0  김철수  90.0
1  이영희   NaN
2  박민수  70.0
```

이영희의 점수가 `NaN`(결측치)입니다.

## 결측치 확인 — isna()

`isna()`는 각 칸이 결측치인지 True/False로 보여줍니다.

```python
df["점수"].isna()
```

출력:
```
0    False
1     True
2    False
Name: 점수, dtype: bool
```

## 결측치 개수 세기

`isna()`에 `sum()`을 붙이면 결측치 개수를 셀 수 있습니다(True=1).

```python
df["점수"].isna().sum()     # 1
```

전체 표의 열별 결측치 개수도 한 번에 볼 수 있습니다.

```python
df.isna().sum()
```

## 결측치 채우기 — fillna()

`fillna(값)`은 결측치를 지정한 값으로 채웁니다.

```python
df["점수"].fillna(0)        # NaN을 0으로
```

평균으로 채우는 것도 흔한 방법입니다.

```python
df["점수"].fillna(df["점수"].mean())
```

## 결측치 있는 행 삭제 — dropna()

`dropna()`는 결측치가 있는 행을 통째로 지웁니다.

```python
df.dropna()
```

출력:
```
    이름    점수
0  김철수  90.0
2  박민수  70.0
```

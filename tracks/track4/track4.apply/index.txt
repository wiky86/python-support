3:T784,## apply란?

`apply`는 열의 각 값에 함수를 적용해 새로운 값을 만드는 도구입니다. 지금까지 배운 벡터 연산(`+`, `*`)이나 `.str` 메서드로 안 되는, 좀 더 복잡한 처리를 할 때 씁니다. "점수를 등급으로 바꾸기", "조건에 따라 다른 값 넣기" 같은 작업이 대표적입니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 75, 55]
})
```

## 함수를 만들어 적용하기

먼저 점수를 등급으로 바꾸는 함수를 만듭니다.

```python
def to_grade(score):
    if score >= 80:
        return "A"
    elif score >= 60:
        return "B"
    else:
        return "C"
```

이 함수를 `apply`로 점수 열에 적용합니다.

```python
df["등급"] = df["점수"].apply(to_grade)
print(df)
```

출력:
```
    이름  점수 등급
0  김철수  90  A
1  이영희  75  B
2  박민수  55  C
```

각 점수가 함수를 거쳐 등급으로 바뀌었습니다. `apply(to_grade)`는 함수 이름만 넣고 괄호는 붙이지 않는 점에 주의하세요.

## lambda로 간단한 함수 바로 쓰기

간단한 처리는 함수를 따로 정의하지 않고 `lambda`로 한 줄에 쓸 수 있습니다.

```python
df["점수2배"] = df["점수"].apply(lambda x: x * 2)
```

`lambda x: x * 2`는 "x를 받아 x*2를 돌려주는 이름 없는 함수"입니다. `x`가 각 점수 값이 됩니다.

## 조건을 lambda로

```python
df["합격"] = df["점수"].apply(lambda x: "합격" if x >= 60 else "불합격")
```

`값 if 조건 else 다른값` 형태로, 조건에 따라 다른 결과를 냅니다.

3:T715,## 중복 데이터란?

같은 데이터가 두 번 이상 들어간 경우입니다. 데이터를 여러 번 입력했거나 파일을 합치는 과정에서 흔히 생깁니다. 중복이 있으면 집계나 통계가 왜곡되므로, 정제 단계에서 확인하고 제거합니다.

예제 데이터 (박민수가 중복):

```python
import pandas as pd
df = pd.DataFrame({
    "이름": ["김철수", "이영희", "박민수", "박민수"],
    "점수": [90, 85, 70, 70]
})
```

## 중복 여부 확인 — duplicated()

`duplicated()`는 각 행이 (앞에 이미 나온 것과) 중복인지 True/False로 보여줍니다. 처음 나온 행은 False, 두 번째부터 True입니다.

```python
df.duplicated()
```

출력:
```
0    False
1    False
2    False
3     True
dtype: bool
```

마지막 박민수 행(3번)이 앞의 박민수와 같아 True입니다.

## 중복 개수 세기

```python
df.duplicated().sum()     # 1
```

## 중복 제거 — drop_duplicates()

`drop_duplicates()`는 중복된 행을 제거하고, 각 값의 첫 번째만 남깁니다.

```python
df.drop_duplicates()
```

출력:
```
    이름  점수
0  김철수  90
1  이영희  85
2  박민수  70
```

중복이던 3번 행이 사라졌습니다.

## 특정 열 기준으로 중복 제거

`subset`으로 특정 열만 기준 삼아 중복을 판단할 수 있습니다. 예를 들어 이름만 같으면 중복으로 볼 때:

```python
df.drop_duplicates(subset="이름")
```

이름이 같으면 점수가 달라도 중복으로 처리해 첫 번째만 남깁니다.

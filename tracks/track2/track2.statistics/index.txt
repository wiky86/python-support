3:T685,## 배열로 통계 내기

NumPy는 배열의 통계값을 구하는 함수를 기본으로 제공합니다. 합계, 평균, 최댓값 등을 함수 하나로 바로 구할 수 있어, 데이터 요약의 출발점이 됩니다.

## 합계와 평균 — sum, mean

```python
import numpy as np
scores = np.array([90, 80, 70, 60])

scores.sum()     # 300  (합계)
scores.mean()    # 75.0 (평균)
```

두 가지 쓰는 방법이 있습니다. `scores.sum()`처럼 배열 뒤에 붙이거나, `np.sum(scores)`처럼 np의 함수로 쓰거나 결과는 같습니다.

```python
np.sum(scores)    # 300
np.mean(scores)   # 75.0
```

## 최댓값과 최솟값 — max, min

```python
scores = np.array([90, 80, 70, 60])
scores.max()     # 90
scores.min()     # 60
```

## 표준편차 — std

표준편차는 값들이 평균에서 얼마나 퍼져 있는지를 나타냅니다. 값이 크면 들쭉날쭉, 작으면 고르게 모여 있다는 뜻입니다.

```python
scores = np.array([90, 80, 70, 60])
scores.std()     # 11.180...
```

지금은 "퍼짐의 정도를 나타내는 값" 정도로 이해하면 충분합니다.

## 최댓값의 위치 — argmax

값 자체가 아니라 "몇 번째가 가장 큰가"를 알고 싶을 때 `argmax`를 씁니다.

```python
scores = np.array([90, 80, 70, 60])
scores.argmax()   # 0  (0번이 가장 큼)
scores.argmin()   # 3  (3번이 가장 작음)
```

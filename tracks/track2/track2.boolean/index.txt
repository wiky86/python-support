3:T6a9,## 조건으로 값 골라내기

boolean indexing은 조건에 맞는 값만 배열에서 골라내는 기능입니다. "60점 이상만", "0보다 큰 값만"처럼 데이터를 걸러낼 때 핵심적으로 쓰입니다.

## 배열에 조건을 걸면 True/False 배열이 나온다

```python
import numpy as np
scores = np.array([90, 50, 80, 40])
scores >= 60
# [ True False  True False]
```

각 값이 조건을 만족하는지 하나씩 판단해, 같은 크기의 True/False 배열이 나옵니다. 90은 60 이상이라 True, 50은 아니라 False입니다.

## True/False 배열로 값 걸러내기

이 True/False 배열을 대괄호에 넣으면, True인 위치의 값만 골라냅니다.

```python
scores = np.array([90, 50, 80, 40])
scores[scores >= 60]
# [90 80]
```

`scores[scores >= 60]`은 "scores 중 60 이상인 값만"이라고 읽으면 됩니다. 데이터 분석에서 가장 자주 쓰는 패턴 중 하나입니다.

## 다양한 조건

```python
arr = np.array([1, -2, 3, -4, 5])

arr[arr > 0]      # [1 3 5]   (양수만)
arr[arr < 0]      # [-2 -4]   (음수만)
arr[arr != 0]     # [ 1 -2  3 -4  5]  (0이 아닌 값)
```

## 조건을 만족하는 개수 세기

True는 1, False는 0으로 취급되므로, 조건 배열에 `sum()`을 쓰면 조건을 만족하는 개수를 셀 수 있습니다.

```python
scores = np.array([90, 50, 80, 40])
(scores >= 60).sum()    # 2  (60 이상인 값이 2개)
```

## 조건으로 값 바꾸기

조건에 맞는 위치의 값만 한 번에 바꿀 수도 있습니다.

```python
scores = np.array([90, 50, 80, 40])
scores[scores < 60] = 0
print(scores)     # [90  0 80  0]
```

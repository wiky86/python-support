3:T655,## 벡터 연산이란?

벡터 연산은 배열 전체에 계산을 한 번에 적용하는 것입니다. 반복문 없이 모든 값에 동시에 연산이 이루어져, 코드가 짧고 계산도 빠릅니다. NumPy를 쓰는 가장 큰 이유입니다.

## 배열과 숫자의 연산

배열에 숫자를 연산하면 모든 값에 똑같이 적용됩니다.

```python
import numpy as np
arr = np.array([1, 2, 3, 4])

arr + 10     # [11 12 13 14]
arr * 2      # [2 4 6 8]
arr - 1      # [0 1 2 3]
arr / 2      # [0.5 1.  1.5 2. ]
```

## 반복문과 비교

리스트로 같은 일을 하려면 반복문이 필요합니다.

```python
# 리스트 방식
nums = [1, 2, 3, 4]
result = []
for n in nums:
    result.append(n * 2)
# result = [2, 4, 6, 8]

# 배열 방식 — 한 줄
arr = np.array([1, 2, 3, 4])
result = arr * 2
```

배열 방식이 훨씬 간결합니다. 데이터가 많을수록 속도 차이도 커집니다.

## 배열끼리의 연산

같은 크기의 배열끼리 연산하면, 같은 위치의 값끼리 계산됩니다.

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

a + b     # [11 22 33]
a * b     # [10 40 90]
```

`a + b`는 1+10, 2+20, 3+30처럼 짝을 지어 계산합니다.

3:T74d,## NumPy와 배열이란?

NumPy는 숫자 데이터를 빠르고 편하게 다루는 파이썬 라이브러리입니다. 핵심 도구는 배열(ndarray)로, 리스트와 비슷하지만 수치 계산에 훨씬 강력합니다. pandas도 내부적으로 NumPy를 쓰기 때문에, 데이터 분석의 토대가 됩니다.

## 불러오기 — import

NumPy는 관례적으로 `np`라는 별명으로 불러옵니다.

```python
import numpy as np
```

거의 모든 코드에서 이 한 줄로 시작합니다. `as np`는 "앞으로 numpy를 np로 부르겠다"는 뜻입니다.

## 리스트로 배열 만들기 — np.array()

```python
import numpy as np
arr = np.array([1, 2, 3, 4])
print(arr)        # [1 2 3 4]
```

리스트를 `np.array()`에 넣으면 배열이 됩니다. 출력할 때 리스트와 달리 쉼표 없이 표시되는 점에 주목하세요.

## 배열과 리스트의 차이

리스트는 값을 하나씩 처리해야 하지만, 배열은 전체에 한 번에 계산을 적용할 수 있습니다(다음 토픽에서 자세히).

```python
nums = [1, 2, 3]
nums * 2          # [1, 2, 3, 1, 2, 3]  (리스트는 반복)

arr = np.array([1, 2, 3])
arr * 2           # [2 4 6]  (배열은 각 값에 곱셈)
```

## 자주 쓰는 배열 생성 함수

| 함수 | 설명 | 예 |
|---|---|---|
| `np.zeros(n)` | 0으로 채운 배열 | `np.zeros(3)` -> `[0. 0. 0.]` |
| `np.ones(n)` | 1로 채운 배열 | `np.ones(3)` -> `[1. 1. 1.]` |
| `np.arange(n)` | 0부터 n-1까지 | `np.arange(5)` -> `[0 1 2 3 4]` |

`np.arange`는 파이썬의 `range`와 비슷하지만 배열을 만든다는 점이 다릅니다.

## 배열의 정보 — shape, dtype

```python
arr = np.array([1, 2, 3, 4])
arr.shape    # (4,)      값이 4개
arr.dtype    # int64     정수형
```

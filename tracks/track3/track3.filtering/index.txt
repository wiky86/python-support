3:T729,## 조건에 맞는 행만 골라내기

데이터 분석에서 가장 자주 하는 일 중 하나는 "조건에 맞는 행만 뽑기"입니다. "점수가 80 이상인 학생", "서울 지역만" 같은 필터링이죠. 트랙2에서 배운 NumPy의 boolean indexing과 원리가 같습니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "이름": ["김철수", "이영희", "박민수", "최지우"],
    "점수": [90, 60, 85, 50]
})
```

## 열에 조건을 걸면 True/False Series가 나온다

```python
df["점수"] >= 80
```

출력:
```
0     True
1    False
2     True
3    False
Name: 점수, dtype: bool
```

각 행이 조건을 만족하는지 True/False로 나옵니다.

## 조건으로 행 걸러내기

이 True/False를 대괄호에 넣으면, True인 행만 남습니다.

```python
df[df["점수"] >= 80]
```

출력:
```
    이름  점수
0  김철수  90
2  박민수  85
```

`df[df["점수"] >= 80]`은 "점수가 80 이상인 행만"이라고 읽으면 됩니다. 원래 인덱스(0, 2)가 그대로 유지되는 점에 주목하세요.

## 여러 조건 결합 — & (그리고), | (또는)

조건을 두 개 이상 걸 때는 `&`(그리고), `|`(또는)로 연결하고, 각 조건을 괄호로 감쌉니다.

```python
# 점수가 60 이상 AND 90 미만
df[(df["점수"] >= 60) & (df["점수"] < 90)]
```

괄호를 빼먹으면 에러가 나므로 각 조건을 반드시 괄호로 묶어야 합니다.

## 조건을 만족하는 행 수 세기

필터링한 결과에 `len()`을 쓰면 조건에 맞는 행의 개수를 알 수 있습니다.

```python
len(df[df["점수"] >= 80])     # 2
```

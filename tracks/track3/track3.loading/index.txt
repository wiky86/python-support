3:T7bf,## 데이터는 어디서 오나?

실제 분석에서는 데이터를 직접 타이핑하기보다 이미 있는 데이터를 불러옵니다. pandas는 여러 형식의 데이터를 DataFrame으로 읽어올 수 있는데, 이번엔 가장 기본이 되는 두 가지 개념을 익힙니다: 코드 안의 딕셔너리로 만들기, 그리고 CSV 파일 읽기.

## 방법 1 — 딕셔너리로 직접 만들기

앞 토픽에서 배운 방식입니다. 작은 데이터를 코드 안에서 만들 때 씁니다.

```python
import pandas as pd
df = pd.DataFrame({
    "이름": ["김철수", "이영희"],
    "점수": [90, 85]
})
```

이 학습 공간의 미니 프로젝트도 이 방식으로 소형 데이터를 만듭니다.

## 방법 2 — CSV 파일 읽기

CSV는 값을 쉼표로 구분한 표 형식의 텍스트 파일입니다. 엑셀에서도 열 수 있는 가장 흔한 데이터 형식으로, `pd.read_csv()`로 읽습니다.

```python
df = pd.read_csv("students.csv")
```

이 한 줄이면 파일 전체가 DataFrame으로 들어옵니다. 파일 경로(이름)를 문자열로 넣어줍니다.

## CSV 파일의 생김새

`students.csv` 파일 내용이 이렇다면:

```
이름,점수
김철수,90
이영희,85
```

읽어들이면 이렇게 됩니다:

```
    이름  점수
0  김철수  90
1  이영희  85
```

첫 줄(이름,점수)이 자동으로 열 이름이 되고, 나머지가 데이터 행이 됩니다.

## 읽은 뒤 첫 확인 습관

CSV를 읽으면 데이터가 제대로 들어왔는지 먼저 확인하는 게 좋습니다.

```python
df = pd.read_csv("students.csv")
df.head()      # 앞부분 확인
df.shape       # 크기 확인
```

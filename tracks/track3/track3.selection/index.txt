3:T724,## 표에서 원하는 부분만 꺼내기

DataFrame에서 특정 열, 특정 행, 또는 특정 칸을 꺼내는 방법을 배웁니다. 이것은 데이터 분석에서 가장 기본이 되는 동작입니다. 세 가지 도구를 씁니다: `[]`(열 선택), `loc`(라벨 기준), `iloc`(위치 기준).

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 70]
})
```

## 열 선택 — 대괄호 []

열 이름을 대괄호에 넣으면 그 열(Series)이 나옵니다.

```python
df["이름"]        # 이름 열
```

여러 열을 뽑을 때는 열 이름 리스트를 넣습니다. 이때는 결과가 DataFrame입니다.

```python
df[["이름", "점수"]]     # 두 열 (대괄호 두 겹)
```

## 행 선택 — loc (라벨 기준)

`loc`는 행의 라벨(인덱스)로 행을 꺼냅니다.

```python
df.loc[0]         # 0번 행 전체
```

출력:
```
이름    김철수
점수     90
Name: 0, dtype: object
```

## 행 선택 — iloc (위치 기준)

`iloc`는 행의 순서 위치(0부터)로 꺼냅니다. 지금 예제는 인덱스가 0,1,2라 loc와 결과가 같아 보이지만, 인덱스가 라벨(예: 이름)일 때 차이가 납니다.

```python
df.iloc[0]        # 첫 번째 행 (위치 0)
```

## 특정 칸 하나 꺼내기 — loc[행, 열]

행과 열을 함께 지정하면 특정 칸의 값을 꺼냅니다.

```python
df.loc[1, "점수"]      # 1번 행의 점수 = 85
```

3:T6c4,## pandas와 Series란?

pandas는 표 형태의 데이터를 다루는 파이썬 라이브러리로, 데이터 분석의 핵심 도구입니다. 엑셀 시트를 파이썬에서 다룬다고 생각하면 쉽습니다. 그 기본 단위가 Series와 DataFrame인데, 이번엔 Series를 배웁니다.

## 불러오기 — import

pandas는 관례적으로 `pd`라는 별명으로 불러옵니다.

```python
import pandas as pd
```

NumPy의 `np`처럼, pandas는 거의 항상 `pd`로 씁니다.

## Series는 "이름표가 붙은 1차원 데이터"

Series는 값들의 나열(리스트나 배열과 비슷)에, 각 값마다 라벨(인덱스)이 붙은 구조입니다. 엑셀의 한 열(column)이라고 보면 됩니다.

```python
import pandas as pd
s = pd.Series([90, 85, 70])
print(s)
```

출력:
```
0    90
1    85
2    70
dtype: int64
```

왼쪽의 0, 1, 2가 인덱스(라벨), 오른쪽이 값입니다. 인덱스를 지정하지 않으면 0부터 자동으로 붙습니다.

## 인덱스를 직접 지정하기

숫자 대신 의미 있는 라벨을 붙일 수 있습니다.

```python
s = pd.Series([90, 85, 70], index=["국어", "영어", "수학"])
print(s)
```

출력:
```
국어    90
영어    85
수학    70
dtype: int64
```

## 값 꺼내기 — 라벨로 접근

딕셔너리처럼 라벨로 값을 꺼냅니다.

```python
s["영어"]     # 85
```

## Series에도 통계 함수가 있다

NumPy 배열처럼 통계 함수를 바로 쓸 수 있습니다.

```python
s.mean()     # 81.666...
s.max()      # 90
s.sum()      # 245
```

3:T695,## 표의 열을 다루기

분석 과정에서 새 열을 만들거나, 필요 없는 열을 지우거나, 열 이름을 바꾸는 일이 자주 생깁니다. 이번엔 이 세 가지를 배웁니다.

예제 데이터:

```python
import pandas as pd
df = pd.DataFrame({
    "이름": ["김철수", "이영희"],
    "국어": [90, 80],
    "영어": [85, 95]
})
```

## 새 열 추가하기

없는 열 이름에 값을 지정하면 새 열이 추가됩니다.

```python
df["반"] = [1, 2]
```

기존 열을 계산해서 새 열을 만들 수도 있습니다. 이것이 실전에서 특히 유용합니다.

```python
df["총점"] = df["국어"] + df["영어"]
```

`df["국어"] + df["영어"]`는 두 열의 같은 행끼리 더해집니다(벡터 연산). 김철수는 175, 이영희는 175가 됩니다.

## 열 삭제하기 — drop

`drop`으로 열을 지웁니다. `axis=1`은 "열을 지운다"는 뜻입니다(행은 axis=0).

```python
df = df.drop("반", axis=1)
```

`drop`은 원본을 바로 바꾸지 않고 지운 결과를 새로 돌려주므로, 보통 `df = df.drop(...)`처럼 다시 담습니다.

## 열 이름 바꾸기 — rename

`rename`에 `columns` 딕셔너리로 "바꿀 이름: 새 이름"을 지정합니다.

```python
df = df.rename(columns={"국어": "국어점수"})
```

여러 개를 한 번에 바꿀 수도 있습니다.

```python
df = df.rename(columns={"국어": "국어점수", "영어": "영어점수"})
```

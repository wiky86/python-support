3:T6a6,## 리스트란?

리스트는 여러 값을 순서대로 담는 상자입니다. 앞 토픽에서 변수 하나에 값 하나를 담았다면, 리스트는 하나의 변수에 여러 값을 담습니다. 데이터 분석에서 "학생 5명의 점수", "월별 매출" 같은 여러 값의 묶음을 다룰 때 기본이 됩니다.

```python
scores = [90, 85, 70, 60, 95]
```

대괄호 `[]` 안에 값을 쉼표로 구분해 넣습니다. 숫자, 문자열 등 어떤 자료형이든 담을 수 있습니다.

```python
cities = ["서울", "부산", "대구"]
```

## 인덱싱 — 값 하나 꺼내기

리스트 안의 각 값에는 순서 번호(인덱스)가 있습니다. 0부터 시작한다는 점이 핵심입니다.

```python
scores = [90, 85, 70, 60, 95]
#          0   1   2   3   4
scores[0]   # 90  (첫 번째)
scores[2]   # 70  (세 번째)
```

## 음수 인덱스 — 뒤에서 세기

`-1`은 맨 마지막, `-2`는 뒤에서 두 번째입니다.

```python
scores[-1]   # 95  (마지막)
scores[-2]   # 60
```

## 슬라이싱 — 여러 값 잘라내기

`[시작:끝]`으로 리스트의 일부를 잘라냅니다. 시작은 포함, 끝은 불포함입니다.

```python
scores = [90, 85, 70, 60, 95]
scores[1:3]   # [85, 70]  (1번부터 2번까지, 3번은 제외)
```

시작이나 끝을 생략할 수도 있습니다.

```python
scores[:2]    # [90, 85]   (처음부터 2번 전까지)
scores[3:]    # [60, 95]   (3번부터 끝까지)
```

## 리스트의 길이 — len()

```python
len(scores)   # 5
```

변수와 자료형

파이썬 기초 다지기 • 5개 실습 • 5개 퀴즈

변수란?

변수는 값을 담아두는 상자입니다. 데이터 분석에서는 숫자, 이름, 참/거짓 같은 값을 변수에 담아 두고 필요할 때 꺼내 씁니다.

score = 90
name = "홍길동"

=는 "같다"가 아니라 "오른쪽 값을 왼쪽 변수에 넣어라"라는 뜻입니다. 위에서 score라는 상자에 90을, name이라는 상자에 "홍길동"을 넣었습니다.

데이터 분석에서 자주 쓰는 4가지 자료형

자료형이름예시쓰임
int정수90, -3, 0개수, 나이, 점수
float실수3.14, 98.6평균, 비율, 측정값
str문자열"홍길동", "서울"이름, 지역, 범주
bool불리언True, False조건 판단, 필터링

정수(int)와 실수(float)

정수는 소수점이 없는 숫자, 실수는 소수점이 있는 숫자입니다. 데이터 분석에서 평균을 내면 대부분 실수가 됩니다.

count = 5        # int
average = 4.2    # float

문자열(str)

글자는 반드시 따옴표로 감쌉니다. 작은따옴표(')와 큰따옴표(") 둘 다 되지만, 하나로 통일하는 게 좋습니다.

city = "서울"

따옴표를 빼먹으면 파이썬은 그걸 변수 이름으로 착각해서 에러가 납니다.

불리언(bool)

참(True) 또는 거짓(False) 두 가지 값만 가집니다. 첫 글자가 대문자라는 점에 주의하세요. 나중에 "점수가 60점 이상인가?" 같은 조건을 다룰 때 핵심이 됩니다.

passed = True

자료형 확인하기 — type()

어떤 값이 무슨 자료형인지 궁금하면 type()으로 확인합니다.

type(90)       # <class 'int'>
type(4.2)      # <class 'float'>
type("서울")    # <class 'str'>
type(True)     # <class 'bool'>
개념을 익혔다면 빈칸 채우기 실습을 진행해 보세요.

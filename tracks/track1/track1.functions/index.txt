3:T73f,## 함수란?

함수는 자주 쓰는 코드에 이름을 붙여 재사용하는 도구입니다. 데이터 분석에서 "평균 구하기", "데이터 정리하기"처럼 반복되는 작업을 함수로 만들어 두면 필요할 때마다 이름만 불러 쓸 수 있습니다. 이미 써본 `print()`, `len()`, `type()`도 함수예요.

## 함수 정의하기 — def

```python
def greet():
    print("안녕하세요")
```

`def 함수이름():` 으로 정의하고, 들여쓴 곳에 실행할 코드를 씁니다. 정의만으로는 실행되지 않고, 이름을 불러야(호출) 실행됩니다.

```python
greet()     # "안녕하세요" 출력
```

## 입력값 받기 — 매개변수

괄호 안에 값을 받아 함수 안에서 활용할 수 있습니다.

```python
def greet(name):
    print(name + "님 환영합니다")

greet("홍길동")    # "홍길동님 환영합니다"
```

`name`을 매개변수라 하고, 호출할 때 넣는 `"홍길동"`을 인자라고 합니다.

## 결과 돌려주기 — return

함수가 계산한 값을 밖으로 돌려줄 때 `return`을 씁니다. `print`는 화면에 보여줄 뿐이고, `return`은 값을 넘겨줘서 다시 활용할 수 있게 합니다.

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)      # 8
```

## 평균 구하는 함수 예시

```python
def average(numbers):
    return sum(numbers) / len(numbers)

scores = [90, 80, 70]
print(average(scores))    # 80.0
```

`sum()`은 리스트 합계, `len()`은 개수를 구하는 내장 함수입니다.

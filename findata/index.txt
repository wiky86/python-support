3:T771,## 수익률이란

주가가 10000원에서 10500원이 되면 얼마나 오른 걸까요? '500원 올랐다'보다 **'5% 올랐다'** 가 더 유용합니다. 주가 수준이 달라도 비교할 수 있기 때문입니다. 이 '%로 표현한 변화'가 **수익률(return)** 입니다.

## 수익률 공식

```
수익률(%) = (나중 값 - 처음 값) / 처음 값 × 100
```

예를 들어 10000원 → 10500원이면:

```python
r = (10500 - 10000) / 10000 * 100
print(r)   # 5.0
```

5%가 나옵니다. 이것이 금융 데이터 분석의 가장 기본 계산입니다.

## 전체 기간 수익률

1월(10000)부터 12월(13500)까지 전체 수익률을 구해봅시다.

```python
prices = [10000, ..., 13500]
total_return = (prices[-1] - prices[0]) / prices[0] * 100
print(round(total_return, 2))   # 35.0
```

1년 동안 35% 올랐습니다. `prices[-1]`(마지막, 12월)에서 `prices[0]`(처음, 1월)을 빼서 계산합니다.

## 월별 수익률 (전월 대비)

매달 전월 대비 얼마나 변했는지도 구할 수 있습니다. 반복문으로 '이번 달 - 지난 달'을 계산합니다.

```python
returns = []
for i in range(1, len(prices)):
    r = (prices[i] - prices[i-1]) / prices[i-1] * 100
    returns.append(round(r, 2))
print(returns)
# [5.0, -2.86, 7.84, 4.55, -2.61, 7.14, -1.67, 5.93, 4.0, -2.31, 6.3]
```

- `range(1, len(prices))`: 2월(인덱스 1)부터 시작합니다. 1월은 '전월'이 없으니 제외합니다.
- `prices[i] - prices[i-1]`: 이번 달에서 지난 달을 뺍니다.
- 양수면 올랐고(예: 5.0), 음수면 내린 것입니다(예: -2.86).

## 정리

수익률은 '(나중-처음)/처음 × 100'으로 구하는, %로 표현한 변화입니다. 전체 기간 수익률은 처음과 끝으로, 월별 수익률은 반복문으로 전월과 비교해 구합니다. 금융 데이터 분석의 가장 기본이 되는 계산입니다.4:T9a2,## 수익률을 요약하기

앞에서 월별 수익률 리스트를 만들었습니다.

```python
returns = [5.0, -2.86, 7.84, 4.55, -2.61, 7.14, -1.67, 5.93, 4.0, -2.31, 6.3]
```

이 11개 숫자를 하나하나 보는 것보다, **요약 값** 몇 개로 '이 주식이 어땠는지'를 파악하는 것이 분석입니다.

## 평균 수익률

매달 평균 몇 %씩 움직였는지 봅니다.

```python
avg_return = sum(returns) / len(returns)
print(round(avg_return, 2))   # 2.85
```

평균 월수익률이 **2.85%** 입니다. 매달 평균적으로 2.85%씩 올랐다는 뜻이니, 전반적으로 상승세였다고 읽을 수 있습니다.

## 변동성 (얼마나 출렁였나)

평균만으로는 부족합니다. '안정적으로 2.85%씩'인지 '어떤 달은 +7%, 어떤 달은 -3%로 출렁이며 평균이 2.85%'인지 구분해야 합니다. 이 **출렁임의 정도**가 변동성이고, **표준편차**로 잽니다.

```python
import statistics
volatility = statistics.pstdev(returns)
print(round(volatility, 2))   # 4.08
```

표준편차가 **4.08** 입니다. 숫자가 클수록 수익률이 들쭉날쭉(위험)하고, 작을수록 안정적입니다. 금융에서 변동성은 곧 '위험'을 나타내는 핵심 지표입니다.

## 최고·최저 월수익률

```python
print(max(returns))   # 7.84  (가장 많이 오른 달)
print(min(returns))   # -2.86 (가장 많이 내린 달)
```

## 상승한 달 세기

```python

```

수익률이 양수인(오른) 달이 몇 개월인지 셉니다. 11개월 중 7개월 상승이니, 오른 달이 더 많았습니다. 트랙5·6에서 배운 컴프리헨션과 조건이 여기서 쓰입니다.

## 숫자를 '해석'하기

분석의 마무리는 숫자를 말로 바꾸는 것입니다.

- 전체 수익률 35%, 평균 월수익률 2.85% → '1년간 꾸준히 상승'
- 변동성 4.08, 상승 7개월/하락 4개월 → '상승세지만 중간중간 출렁임이 있었다'

이렇게 숫자에서 의미를 읽어내는 것이 데이터 분석의 진짜 목적입니다.

## 정리

수익률 리스트를 평균(sum/len), 변동성(표준편차), 최고·최저, 상승 달 수로 요약하면 주식의 성격을 파악할 수 있습니다. 평균은 '얼마나 올랐나', 변동성은 '얼마나 위험한가'를 말해줍니다. 숫자를 해석해 의미로 바꾸는 것이 분석의 목적입니다.5:T783,## 환율도 변동률로

주가에서 수익률을 구했듯, 환율도 **변동률**(전월 대비 몇 % 변했나)을 구합니다. 공식은 똑같습니다.

```
변동률(%) = (이번 달 - 지난 달) / 지난 달 × 100
```

```python
rates = [1300, 1320, 1290, ...]
changes = []
for i in range(1, len(rates)):
    c = (rates[i] - rates[i-1]) / rates[i-1] * 100
    changes.append(round(c, 2))
print(changes)
# [1.54, -2.27, 4.65, 2.22, -2.9, -2.24, 3.82, 2.94, -2.14, 3.65, -2.11]
```

- 양수(+1.54): 환율 상승 = 원화 약세
- 음수(-2.27): 환율 하락 = 원화 강세

## 환율 변동성

환율도 표준편차로 변동성을 잽니다.

```python
import statistics
volatility = statistics.pstdev(changes)
print(round(volatility, 2))   # 2.84
```

변동성이 **2.84** 입니다. 환율 변동성이 크면 수출입 기업의 계획이 불확실해지고, 환위험 관리가 중요해집니다. 금융 과목에서 배운 '환위험 헤지'가 바로 이 변동성에 대응하는 것입니다.

## 원화 강세였던 달 세기

변동률이 음수인(환율 하락 = 원화 강세) 달은 5개월입니다. 11개월 중 5개월은 원화 강세, 6개월은 약세였습니다.

## 정리

```python

```

`items()`로 카테고리와 금액을 함께 꺼내 각 비중을 계산합니다. 주거가 40%로 가장 큰 비중입니다.

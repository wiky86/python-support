3:T9a2,## 수익률을 요약하기

앞에서 월별 수익률 리스트를 만들었습니다.

```python
returns = [5.0, -2.86, 7.84, 4.55, -2.61, 7.14, -1.67, 5.93, 4.0, -2.31, 6.3]
```

이 11개 숫자를 하나하나 보는 것보다, **요약 값** 몇 개로 '이 주식이 어땠는지'를 파악하는 것이 분석입니다.

## 평균 수익률

매달 평균 몇 %씩 움직였는지 봅니다.

```python
avg_return = sum(returns) / len(returns)
print(round(avg_return, 2))   # 2.85
```

평균 월수익률이 **2.85%** 입니다. 매달 평균적으로 2.85%씩 올랐다는 뜻이니, 전반적으로 상승세였다고 읽을 수 있습니다.

## 변동성 (얼마나 출렁였나)

평균만으로는 부족합니다. '안정적으로 2.85%씩'인지 '어떤 달은 +7%, 어떤 달은 -3%로 출렁이며 평균이 2.85%'인지 구분해야 합니다. 이 **출렁임의 정도**가 변동성이고, **표준편차**로 잽니다.

```python
import statistics
volatility = statistics.pstdev(returns)
print(round(volatility, 2))   # 4.08
```

표준편차가 **4.08** 입니다. 숫자가 클수록 수익률이 들쭉날쭉(위험)하고, 작을수록 안정적입니다. 금융에서 변동성은 곧 '위험'을 나타내는 핵심 지표입니다.

## 최고·최저 월수익률

```python
print(max(returns))   # 7.84  (가장 많이 오른 달)
print(min(returns))   # -2.86 (가장 많이 내린 달)
```

## 상승한 달 세기

```python
up_months = len([r for r in returns if r > 0])
print(up_months)   # 7
```

수익률이 양수인(오른) 달이 몇 개월인지 셉니다. 11개월 중 7개월 상승이니, 오른 달이 더 많았습니다. 트랙5·6에서 배운 컴프리헨션과 조건이 여기서 쓰입니다.

## 숫자를 '해석'하기

분석의 마무리는 숫자를 말로 바꾸는 것입니다.

- 전체 수익률 35%, 평균 월수익률 2.85% → '1년간 꾸준히 상승'
- 변동성 4.08, 상승 7개월/하락 4개월 → '상승세지만 중간중간 출렁임이 있었다'

이렇게 숫자에서 의미를 읽어내는 것이 데이터 분석의 진짜 목적입니다.

3:T771,## 수익률이란

주가가 10000원에서 10500원이 되면 얼마나 오른 걸까요? '500원 올랐다'보다 **'5% 올랐다'** 가 더 유용합니다. 주가 수준이 달라도 비교할 수 있기 때문입니다. 이 '%로 표현한 변화'가 **수익률(return)** 입니다.

## 수익률 공식

```
수익률(%) = (나중 값 - 처음 값) / 처음 값 × 100
```

예를 들어 10000원 → 10500원이면:

```python
r = (10500 - 10000) / 10000 * 100
print(r)   # 5.0
```

5%가 나옵니다. 이것이 금융 데이터 분석의 가장 기본 계산입니다.

## 전체 기간 수익률

1월(10000)부터 12월(13500)까지 전체 수익률을 구해봅시다.

```python
prices = [10000, ..., 13500]
total_return = (prices[-1] - prices[0]) / prices[0] * 100
print(round(total_return, 2))   # 35.0
```

1년 동안 35% 올랐습니다. `prices[-1]`(마지막, 12월)에서 `prices[0]`(처음, 1월)을 빼서 계산합니다.

## 월별 수익률 (전월 대비)

매달 전월 대비 얼마나 변했는지도 구할 수 있습니다. 반복문으로 '이번 달 - 지난 달'을 계산합니다.

```python
returns = []
for i in range(1, len(prices)):
    r = (prices[i] - prices[i-1]) / prices[i-1] * 100
    returns.append(round(r, 2))
print(returns)
# [5.0, -2.86, 7.84, 4.55, -2.61, 7.14, -1.67, 5.93, 4.0, -2.31, 6.3]
```

- `range(1, len(prices))`: 2월(인덱스 1)부터 시작합니다. 1월은 '전월'이 없으니 제외합니다.
- `prices[i] - prices[i-1]`: 이번 달에서 지난 달을 뺍니다.
- 양수면 올랐고(예: 5.0), 음수면 내린 것입니다(예: -2.86).
